Platform Settings

The Settings section of the admin panel is where you configure how the entire platform operates. Changes here affect every part of the website, so take your time and double-check values before saving.

General settings

Section titled “General settings”

This is where you set up the basics:

  • Site name — The platform name that appears in the header, emails, and browser tab (e.g., “BYNDIO”).
  • Site description — A short tagline used for search engines and social media sharing.
  • Logo — The main logo that appears in the header and footer.
  • Favicon — The small icon that appears in the browser tab.
  • Contact email — The email address shown on the Contact page and in support-related communications.
  • Phone number — Displayed on the website for customer enquiries.
  • Currency — The currency symbol (e.g., INR) and currency code used across the platform. This affects how prices are displayed everywhere — product pages, cart, checkout, invoices.
  • Social media links — Links to the platform’s Facebook, Instagram, Twitter/X, YouTube, and other social accounts. These appear in the website footer.

Payment settings

Section titled “Payment settings”

This section controls how customers pay and how the platform earns:

  • Payment gateways — Enable or disable the available payment providers (Stripe, Razorpay). When a gateway is enabled, it appears as a payment option during checkout.
  • API keys — Each gateway needs its own set of keys (public key and secret key) to work. You get these from the payment provider’s dashboard. Be very careful here — entering incorrect keys will break checkout for all customers.
  • Commission rates — Set the default platform commission percentage taken from each sale. Note that category-level commission rates (set in the Categories section) override this default.
  • Withdrawal amounts — Set the minimum and maximum amounts that sellers, influencers, and affiliates can withdraw from their wallets. The minimum prevents tiny payouts that are not worth processing. The maximum can be used as a safety measure.

Shipping settings

Section titled “Shipping settings”

If you use Shiprocket for shipping:

  • Enable/disable — Turn the Shiprocket integration on or off.
  • Credentials — Enter your Shiprocket API email and password. The platform uses these to create shipments, generate tracking numbers, and fetch delivery status updates automatically.
  • Default shipping rules — Configure default behaviours like free shipping thresholds, standard delivery charges, and handling times.

When Shiprocket is enabled, sellers can ship orders through it directly from their dashboard. Tracking updates come into the platform automatically.

SMS settings

Section titled “SMS settings”

For sending OTP codes and transactional messages:

  • Enable/disable — Turn SMS notifications on or off.
  • Provider — Configure MSG91 as the SMS provider. Enter your API key and sender ID.
  • OTP verification — When enabled, new users receive an OTP during registration and must verify their phone number.

Things to keep in mind

Section titled “Things to keep in mind”

All settings take effect immediately. There is no “staging” or “preview” mode. When you click save, the changes are live.

Payment gateway keys are sensitive. If you are switching from test/sandbox keys to live keys, make sure you have the right ones. Test keys will not process real payments, and live keys pointed at a test environment can cause confusion.

Currency changes are cosmetic. Changing the currency symbol and code updates how prices are displayed, but it does not convert existing prices. If you switch from INR to USD, a product priced at 500 will now show as $500 (which is probably not what you want). Only change currency during initial setup or after careful planning.

Shipping credentials expire. If order shipping suddenly stops working, check whether your Shiprocket credentials are still valid. Re-enter them if needed.

Commission rates stack. If you set a default commission of 10% and a category commission of 15%, the category rate wins for products in that category. All other products use the default.
